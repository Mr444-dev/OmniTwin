# Unity client setup

The user-created **OmniTwin.Unity** project is here, using **Unity 6000.6.3f1 → Universal 3D**. Open **Assets/_OmniTwin/Scenes/TacticalDesk.unity** and follow the [integrated scene guide](../docs/unity-scene.md).

The [setup guide in Polish](../docs/unity-setup.md) remains a reference for recreating a separate project's Hub location, packages, Player settings, and backend boundary.

Client sources are provided in `client/Runtime`. After creating the project, use the [import and scene wiring guide](../docs/unity-client.md) to install the actual portable runtime DLLs and these scripts.
