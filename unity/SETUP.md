# Unity client setup

Create **OmniTwin.Unity** in this directory using **Unity 6000.6.7f1 → Universal 3D**.

Follow the [complete setup guide in Polish](../docs/unity-setup.md) for the Hub location, supported packages, Player settings, and the .NET 10 backend boundary. The user creates this project manually; no Unity scene, manifest, or project settings have been generated here.
